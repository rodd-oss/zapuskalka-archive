# Подписи / Signatures

В этой папке хранятся подписи авторов под [Соглашением об отчуждении исключительного права на вклад в проект Zapuskalka](../RIGHTS-TRANSFER.md). Одна подпись — один файл `<github-login>.md`, добавленный самим автором.

This folder holds the contributors' signatures under the [Zapuskalka Contributor Copyright Assignment Agreement](../RIGHTS-TRANSFER.md). One signature is one file `<github-login>.md`, added by the contributor themselves.

## Как подписать / How to sign

1. Прочитайте [`legal/RIGHTS-TRANSFER.md`](../RIGHTS-TRANSFER.md). / Read [`legal/RIGHTS-TRANSFER.md`](../RIGHTS-TRANSFER.md).
2. Сделайте fork этого репозитория. / Fork this repository.
3. Скопируйте [`TEMPLATE.md`](TEMPLATE.md) в `legal/signatures/<ваш-логин-github>.md` и заполните поля: ФИО, логин GitHub, адреса email из ваших коммитов, дату. Текст принятия не меняйте. / Copy [`TEMPLATE.md`](TEMPLATE.md) to `legal/signatures/<your-github-login>.md` and fill in the fields: full name, GitHub login, the e-mail addresses from your commits, the date. Leave the acceptance text unchanged.
4. Сделайте коммит **со своей учётной записи GitHub** (по возможности подписанный: `git commit -S`, чтобы GitHub показал метку Verified). / Commit **from your own GitHub account** (ideally a signed commit, `git commit -S`, so GitHub shows the Verified badge).
5. Откройте pull request в ветку `main` этого репозитория. В pull request не должно быть других изменений. / Open a pull request against `main` of this repository. The pull request must contain no other changes.
6. Соглашение считается заключённым, когда `@milanjrodd` примет pull request. / The Agreement is concluded when `@milanjrodd` merges the pull request.

Вопросы задавайте в issue, которое вам адресовано, или в самом pull request. / Ask questions in the issue addressed to you or in the pull request itself.
